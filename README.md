# Image-to-Video Prompting — visual interactive deck

A custom visual presentation engine with scene-led storytelling, progressive reveal, slide-specific demos, overview, presenter notes, keyboard navigation, timer, blackout and fullscreen.

Reference study: gdgaiforscience/trasformers101 (especially the engine and design spec) and official Runway Image-to-Video prompting materials. This project uses its own original presentation content and visuals rather than copying the reference slides.

Keyboard: Space/right reveal/next; left back; O/Esc overview; N notes; P presenter; T timer; B blackout; F fullscreen; ? help.
