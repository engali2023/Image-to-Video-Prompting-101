# Image-to-Video Prompting — Arabic interactive presentation

Custom slide runtime inspired by the reference presentation architecture: 1920x1080 stage, incremental reveals, demo lifecycle, overview, hash navigation, notes, presenter window, timer, blackout and fullscreen. Original Arabic course content and interactive labs.

Shortcuts: arrows/space reveal; Home/End; O overview; P presenter; N notes; T timer; B blackout; F fullscreen; ? help.
No build step. GitHub Pages deployment workflow included.
